# ملهمين • Story Studio

الموقع العام الرسمي لمشروع **ملهمين**.

واجهة تعريفية عامة تتضمن:

- تعريف المنتج ومنهج التحرير
- سياسة الخصوصية
- شروط الاستخدام
- صفحة الدعم

الموقع لا يحتوي مهارات المشروع الخاصة أو ملفات التشغيل السرية. الحزمة الأساسية محفوظة بشكل منفصل.

- `support.html`

## Deployment
