# ملهمين • Story Studio

الموقع العام والنسخة القابلة للمشاركة من مهارة **ملهمين**.

## تحميل المهارة

- `downloads/molhimeen.skill` — ملف المهارة القابل للمشاركة.
- `downloads/molhimeen-skill-v1.0.0.zip` — نسخة ZIP مطابقة.

## التثبيت في ChatGPT

للحسابات المؤهلة لاستخدام Skills: افتح Skills/Plugins → Create → Upload ثم اختر ملف `molhimeen.skill` أو نسخة ZIP إذا كانت واجهتك تقبلها.

## التثبيت في Codex

يمكن فك الضغط ووضع مجلد المهارة في مسار Skills المدعوم، مع بقاء `SKILL.md` في جذر مجلد المهارة.

## ما الذي تفعله؟

تبحث عن قصص سعودية وخليجية وعربية تستحق النشر، تتحقق من المصادر، تختار الزاوية، تصنع 3 هوكات مختلفة، تكتب الثريد، ثم تراجع المبالغة والصياغة الآلية بدون تغيير الحقائق.

المستودع العام لا يحتوي على أسرار أو مفاتيح API أو بيانات خاصة.
